# ALO 0.14.13

Saved spaces automatically upgrade to the current secure room system. Room IDs,
names, privacy, and icons remain unchanged. Macs with the same private invite key
derive the same upgraded credential; migration is safe to retry after interruption.
There is no legacy transport fallback. Update every participating Mac before rejoining.

The current room protocol generation is required at authenticated admission and
in nearby discovery. Older clients cannot join the upgraded room. Harmless future
patch releases may share a generation; incompatible system changes must bump it.

Fixes first-time secure room creation in Developer-ID Mac builds by using the
Mac login Keychain for installation identities and peer pins. The signed release
is checked for actual identity creation, reload, and pin persistence on a clean Mac.

Legacy discovery records no longer hide an upgraded room with the same ID.
Direct file-transfer failures no longer incorrectly claim a version mismatch.
