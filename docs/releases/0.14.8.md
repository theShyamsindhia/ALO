# ALO 0.14.8

ALO 0.14.8 regenerates the complete app-icon collection against a controlled chroma background, removes that background cleanly, and repairs automatic update installation.

- Regenerates the default icon and all 15 optional icons with their original visual identities intact.
- Removes the background through an edge-connected chroma-key pass so pale and green artwork inside each icon remains preserved.
- Eliminates the generated gray or white bottom skirt from Finder, notifications, the Dock, and the icon picker.
- Refreshes on-demand icon downloads from an immutable source revision and starts a new local icon cache generation.
- Replaces brittle per-image crop assertions with regression checks for complete bodies and transparent padding on every edge.
- Packages the signed app without framework links so existing ALO installations no longer reject the update archive.
- Adds a release gate that prevents another updater-incompatible ZIP from being published.

The release workflow tests the app, signs it with Developer ID, notarizes and staples both downloads, verifies Gatekeeper acceptance, and confirms the updater ZIP is compatible with existing ALO versions before publishing it.
