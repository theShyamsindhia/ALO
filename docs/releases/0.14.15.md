# ALO 0.14.15

- Native blur for the floating player and a translucent menu-bar player surface.
- Gentle, changing album-art colours across the player; neutral blur without artwork.
- Removes the solid black Talk strip while keeping unread badges visible.

- Includes the latest Notch settings motion and clipboard-handling fixes.

Room protocol compatibility is unchanged from 0.14.13 and 0.14.14.

Downloads are attached only after regression tests, room scenarios, signing,
notarization, Gatekeeper and clean-machine distribution checks pass.
