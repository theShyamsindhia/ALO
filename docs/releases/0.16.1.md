# ALO 0.16.1

Intel Mac downloads, a native glass notch, and a clearer What's New screen.

## Intel Macs

- Notarized `x86_64` ZIP and DMG downloads are now published alongside the Apple Silicon builds.
- The updater picks the archive for this Mac's architecture and verifies it in the downloaded app before installing.

## Room notch

- The compact and expanded notch share one continuous native surface: Liquid Glass on macOS 26 and a frosted backdrop on earlier versions. The custom black shell and outline are gone, and the notch stays anchored to the top of the screen while it expands.
- With Reduce Transparency on, the notch uses an opaque window background.
- Room playback uses the standard player layout, with room navigation in the player header instead of a separate strip.
- Live streams without a known duration show "Live audio" instead of an empty scrubber.

## What's New

- A dark, native update window shows each release's notes and support options.

Room audio synchronization and screen-video timing are unchanged. This release does not claim to resolve the previously reported receiver-side video lag.

## Release checks

The full optimized Mac suite, strict audio timing gates, and repeatable room scenarios run on Apple Silicon. Developer ID signing, notarization, Gatekeeper, and clean-machine package checks run separately for Apple Silicon and Intel before publication. The automated tests run on Apple Silicon only; Intel builds are checked for packaging and launch, not full behavior.
