# ALO 0.16.0

A smaller, room-focused notch and a more consistent native Spaces window.

## Spaces window

- Hide or restore the sidebar with its native control or Control–Command–S. Resizing and collapsing preserve the conversation draft.
- Matching sidebar and conversation-panel heights, insets, and corner radii.
- Native sidebar glass on supported macOS versions, with a frosted-material fallback on older systems.
- Steady, correctly inset traffic lights during sidebar transitions; no extra titlebar strip or divider ridge.

## Room notch

- Compact, tray-style room actions and quick tools, with bounded layouts that keep content inside the notch.
- Message and mention previews open the conversation inside the same notch. Notification controls remain available, and incoming previews do not replace an expanded conversation.
- Drag files to room members, the shared room shelf, your local shelf, or the system AirDrop workflow.
- Clearer transfer offers, progress, cancellation, save/export, retry, and temporary-inbox cleanup. Receiving a direct file requires acceptance; room-shelf downloads are explicit.
- Screenshot preview and text extraction, file conversion, downloads, camera mirror, countdown, Clock timer, calendar, and system-statistics tools are reachable from the compact tray. Camera and calendar access remain permission-controlled.
- Countdown completion can play once instead of repeatedly sounding an alarm.

## Shared canvas

- Open a still image and let room members explicitly join a shared drawing canvas.
- Owner-controlled drawing permissions, pause, undo, image replacement, and session ending.
- A separate authenticated, bounded canvas channel with verified image transfers and recovery after interrupted connections.

Room audio synchronization and screen-video timing algorithms are unchanged. This release does not claim to resolve the previously reported receiver-side video lag. Shared canvas requires compatible ALO versions on both ends; AirDrop recipient selection uses Apple's system interface.

## Release checks

Local native-window and feature regressions are supplemented by the full optimized Mac suite, strict audio timing gates, repeatable room scenarios, Mac/iOS builds, Developer ID signing, notarization, and clean-machine package checks before publication. Physical two-Mac canvas interaction under simultaneous audio load is not established by automated loopback coverage.
