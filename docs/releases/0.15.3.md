# ALO 0.15.3

- Open channels directly from the network sidebar with one click.
- Read and write messages in the main window instead of a separate channel-selection page.
- Keep the conversation window open when joining; switch channels after the previous session finishes stopping.
- Show the selected channel and its connected state clearly.
- Use native macOS split navigation, toolbar controls and sidebar styling.
- Keep voice transmission explicit: opening a channel does not enable the microphone.

Validated with actual Dev-app leave/rejoin clicks, preserved chat history,
light/dark window fixtures, and the full Mac/iOS CI run:
https://github.com/theShyamsindhia/ALO/actions/runs/34230363640

This update changes navigation and presentation, not the audio transport.
No new two-Mac acoustic test was performed; the release owner waived that gate.
Signed and notarized downloads are attached only after release checks pass.
