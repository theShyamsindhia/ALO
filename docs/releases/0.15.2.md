# ALO 0.15.2

## Audio reliability

- Improve playback scheduling, bounded audio delivery, late joins and output-route recovery.
- Fence stale voice callbacks across route changes and resets.
- Report playback timeline recovery separately from small clock-offset measurements, so low reported clock drift does not hide playback trouble.
- Add regression coverage for timing, connection teardown and room lifecycle failures.

## Networks and Channels

- Use a compact native Mac window, standard title bar and cleaner sidebar layout.
- Preserve onboarding and identity recovery access while simplifying the network browser.

## Opt-in Codex messaging

- Add explicitly enabled device messaging with authenticated peer transport, local task approval, bounded requests and staged receipts.
- Keep queued and delivered states distinct, with revocation and historical-status controls.

## Validation and limitations

The combined implementation passed 384 XCTest tests, 1,387 Swift tests across
222 suites, seven repeatable room scenarios, and Mac/iOS build checks in
[CI](https://github.com/theShyamsindhia/ALO/actions/runs/34220207975).
Release packaging also requires strict tests, signing, notarization and
relocated-app verification before downloads are attached.

A new physical two-Mac listening test and real selected-Codex-task receipt test
were not performed for this candidate; the release owner explicitly waived the
live-test gate. Automated results do not establish acoustic synchronization on
every hardware or wireless route. This release does not claim all sync issues
are impossible.
