# ALO 0.14.14

Fixes missing Mac Bonjour declarations for current secure room discovery and
media transport. Opening the space list starts a fresh discovery scan, and denied
Local Network access has actionable guidance. The packaged app is checked for
these declarations on the clean distribution runner.

Keeps the current protocol generation: 0.14.13 and 0.14.14 can join each other.
All older incompatible clients must update. Public rooms still require a reachable
local/nearby network and Local Network permission on both devices.

CI now tests and packages concurrently. Separate incremental caches preserve test
and app compiler configurations. Content hashes protect against stale source
timestamps. All live timing, regression, scenario, signature, notarization, and
clean-machine checks remain required before publishing.
