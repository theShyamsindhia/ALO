# ALO 0.14.10

Games opens in a dedicated resizable window from the room controls, Touch Bar and activity invitations. Opening Games again brings the existing window forward without resetting a running match. The full-screen control remains available; games no longer dock back into the room bar.

Playback tracks gradual capture-clock changes as well as abrupt capture gaps, allowing continuous rate correction to follow the source clock between realignments.

Includes the packaged FPS launch fix and per-device timing reports introduced in the 0.14.9 source revision. Older installed versions do not contain these fixes.
