## ALO 0.13.42

- Completes the ALO source/package rebrand, updates remaining room labels and
  service display names, and adds the `alo` launcher. The old launcher and signing
  settings remain compatible.
- Preserves installed-app permissions, saved rooms, separate development data,
  device discovery, and audio-driver compatibility identifiers.
- Fixes durable room synchronization getting stuck when received changes depend
  on changes that have not arrived yet. Pending changes now survive local edits
  and restarts within the existing document-size limit.
- Adds repeatable delayed-network/partition simulations and real local socket
  scenarios covering late joins, repeated rejoins, concurrent media/voice/chat,
  persistence, and receiver continuity. A repeat-run script retains test logs.
- Serializes hardware-dependent voice and large-history sync tests to avoid
  competing graph operations and CPU-heavy fixtures during verification. The
  release workflow now checks the room scenarios before packaging.

These automated scenarios do not certify physical Bluetooth audio quality or
audible synchronization between Macs. No claim of a new Bluetooth-specific fix
is made in this release.
