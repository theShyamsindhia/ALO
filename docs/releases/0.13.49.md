## ALO 0.13.49

- Mute room media now silences only received room audio. It no longer silences this Mac's own broadcast playback. The incoming mute preference is retained when switching between broadcasting and listening; voice and per-device mixer controls remain separate.
- Clicking the menu-bar icon now shows or hides Spaces when outside a room, preserving unfinished input. Inside a room, the existing controls popover still toggles normally.
- Give the Talk bar a pitch-black background with legible controls in either system appearance. Keep the unread-message badge fully visible above its action group, including two-digit counts.

Includes the audio timing, recovery, and private-media protections from 0.13.48. Everyone in a private room should use 0.13.48 or newer.

Validation: 298 tests passed locally, including room/network scenarios and native light/dark UI snapshots. Physical multi-Mac listening and Bluetooth checks are still recommended.
