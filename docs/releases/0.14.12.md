# ALO 0.14.12

Send a file directly to another Mac from its device context menu. Images, movies,
and audio appear in a pinned, borderless media window with hover controls for
saving, choosing a display, and closing. Annotate an image or paused video frame
and send the flattened image back to appear on the other Mac.

Other files require Accept/Decline and a save destination; they never launch an
external app. Transfers run on a separate authenticated TLS connection, with
bounded chunks, pacing, SHA-256 verification, timeout, and cancellation. Supports
regular files up to 1 GB, with four concurrent transfers and four media windows.
Both Macs must update to use direct file sharing. Save received media before
leaving the room; the temporary inbox is cleared on room exit.
