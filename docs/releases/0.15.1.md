# ALO 0.15.1

## Easier setup and joining

- Set up ALO with your name, then save your private recovery key. The main flow
  no longer exposes identity fingerprints or raw key documents.
- Find nearby networks and request to join directly. Owners approve or decline
  inside ALO; exchanging JSON is no longer the primary joining flow.
- Cancel waiting requests and retry discovery failures without locking the rest
  of the interface. Owners need ALO running and reachable for new approvals.
- Discovery is not membership: channels still require a verified, owner-signed
  grant. Nearby names are self-asserted; approve only expected people.

## Reliability

- Fixed new channels failing because the `channels.json` parent folder did not
  exist. Initial event and durable-state writes also prepare their directories.
- Preserve a pending iOS channel join when a permission sheet temporarily makes
  the app inactive. Backgrounding and explicit cancellation still stop stale work.

The identity recovery key remains unencrypted. Keep it private: anyone with the
file can use your identity. Both devices need this update for the new nearby
request-to-join experience. Existing channel authorization is unchanged.
