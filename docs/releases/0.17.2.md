# ALO 0.17.2

A smaller smoking counter and clearer file sharing from the notch.

## Smoking counter

- The menu-bar counter opens below its button and stays on-screen. Opening Details grows the popover downward without moving its anchor.
- Choose a brand and log from a compact view. Earlier time and optional context live under Details; today's count, cost, and History stay close at hand.
- Logging shows an inline Undo for six seconds without making the popover taller.
- The notch temporarily hides while the counter is open, then returns without interrupting playback.
- History's add and edit forms close after saving and support Return to save and Escape to cancel.

## Notch file sharing

- Dragging a file toward the notch reveals destinations before reaching the top edge of the screen. Window and text drags do not reuse an old file drag.
- Private recipients show their avatars in a scrollable row. Everyone, My shelf, and AirDrop have clear destination labels and drop highlighting.
- The recipient chooser has more room for the two destination rows and respects Reduce Motion.

## Known limitations

The previously documented audio sender-tail issue under congested, multi-peer conditions remains deferred. Receiver-side video choppiness is also not addressed by this update. Audio synchronization and video transport are unchanged.

If an older ALO version rejects a valid update archive, install this release manually from the DMG for your Mac to get the updater fix introduced in 0.17.1. Existing data is retained.
