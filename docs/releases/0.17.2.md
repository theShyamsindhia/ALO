# ALO 0.17.2

A smaller smoking counter, calmer notch spacing, streamlined room tools, and a collaborative Figma-style canvas with borderless pop-out.

## Smoking counter

- The menu-bar counter opens below its button and stays on-screen. Opening Details grows the popover downward without moving its anchor.
- Choose a brand and log from a compact view. Earlier time and optional context live under Details; today's count, cost, and History stay close at hand.
- Logging shows an inline Undo for six seconds without making the popover taller.
- The notch temporarily hides while the counter is open, then returns without interrupting playback.
- History's add and edit forms close after saving and support Return to save and Escape to cancel.

## Collaborative canvas & borderless pop-out

- Start an instant dark collaborative board (`New board`), paste an image from the clipboard, or open an image backdrop directly from the notch.
- Pop out the canvas into a borderless, resizable pure-black workspace with floating HUD controls, and shrink it back into the notch at any time.
- Draw crisp, sharp rectangles by default and drag their inner corner-radius handles (or choose `Sharp`, `8`, `20`, `Pill` presets) to round corners live across all collaborators with single-step Undo (`⌘Z`).
- Navigate across the board with two-finger trackpad swipe panning, cursor-anchored two-finger pinch zoom (`⌘`/`⌥` + scroll), `Spacebar` + drag hand panning, and single-key Figma tool shortcuts (`V`, `H`, `R`, `O`, `A`, `P`, `S`).

## Notch file sharing, room layout, and tools

- Dragging a file toward the notch reveals destinations before reaching the top edge of the screen. Window and text drags do not reuse an old file drag.
- Private recipients show their avatars in a scrollable row. Everyone, My shelf, and AirDrop have clear destination labels and drop highlighting.
- Music artwork and the equalizer have more room beside the hardware notch. The player has a labeled Room button and no longer shows the redundant Live audio row.
- Room actions (`Chat`, `Files`, `Canvas`, `Tools`) use a clean 4-column layout with unified pill headers and no inner dividers or stacked back headers.
- Tools focuses on the 4 interactive room utilities (`Screenshots`, `Convert`, `Countdown`, `Camera`) in a single row matching the tray height, preserving selection, screenshots, and conversion settings across notch collapses.

## Known limitations

The previously documented audio sender-tail issue under congested, multi-peer conditions remains deferred. Receiver-side video choppiness is also not addressed by this update. Audio synchronization and video transport are unchanged.

If an older ALO version rejects a valid update archive, install this release manually from the DMG for your Mac to get the updater fix introduced in 0.17.1. Existing data is retained.
