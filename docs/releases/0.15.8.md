# ALO 0.15.8

A more consistent Spaces and conversation window.

- One stable text hierarchy across compact and large windows; resizing changes spacing rather than font sizes.
- Aligned sidebar labels and icons, a quieter network icon, and a clearly separated now-playing footer.
- Removed the selection dot that could be mistaken for an unread-message indicator.
- A behind-window system material with a Reduce Transparency fallback, without the competing outer rounded mask and opaque backing.
- A smaller initial window that fits the available screen, consistent inner corners, and top-aligned headers in empty and connecting states.
- Regression coverage for native window geometry, blur coverage, compact layouts, and stable now-playing typography.

Chat actions, room controls, and compact/notch chat behavior are unchanged. This update does not modify audio synchronization or video timing; the paused receiver-video-lag investigation is not included.

Full Mac tests, room scenarios, the iOS build, signing, notarization, and clean-machine distribution checks must pass before this candidate becomes the stable update. Live two-Mac media behavior is not revalidated by this UI-only release.
