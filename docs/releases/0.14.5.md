## ALO 0.14.5

ALO 0.14.5 fixes the app-icon edge artifacts and includes the completed changes that landed immediately after 0.14.4.

- Replace the hard binary transparency on the default app icon and all 16 selectable variants with a properly feathered, decontaminated alpha edge. This removes the chipped white/gray rim in Settings, Finder, the Dock, and notifications without redrawing the artwork.
- Add a regression check that requires transparent corners and a real antialiased edge on every selectable icon.
- Add opt-in native notch playback and activity controls, with stable lifecycle handling and bounded media caches.
- Clarify room settings, allow live arena joins with smoother multiplayer behavior, and add a Finder action for chat attachments.

The release is built from the latest synchronized `main`, then tested, Developer ID signed, notarized, stapled, and checked with Gatekeeper in CI.
