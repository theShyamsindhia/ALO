# ALO 0.14.9

Fixes the Breach launch crash in installed apps. The game now resolves its texture from the packaged app resources, and missing resources no longer trigger SwiftPM's fatal bundle lookup. Release verification launches the packaged scene on a separate clean machine before publishing downloads.

Playback realigns when a capture timestamp discontinuity would otherwise leave queued audio on an old timeline. Stale or invalid audio-render clocks are shown as unavailable instead of appearing to be fresh zero-drift measurements.

People now shows each device's reported network RTT to the broadcaster and estimated playback drift. Reports expire when no longer fresh; older versions show unavailable. Drift is a software playback estimate, not an acoustic measurement of the speakers. Update all participating Macs to receive these fixes and timing reports.

Automatic updates now use an updater-compatible archive with no framework links. Simultaneous room listening and dialing can safely reuse retiring local TCP endpoints, and a recovered bounded audio path admits fresh waiting sound without letting stale completion history starve one listener.
