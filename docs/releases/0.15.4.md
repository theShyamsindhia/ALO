# ALO 0.15.4

- Fix premature loss of broadcast audio when capture or sender work arrives in a burst.
- Keep valid queued audio within the room's playback budget instead of truncating it at an unrelated 80 ms limit.
- Retain strict memory bounds, playback-deadline expiry, and pause/leave/broadcaster-change cancellation.

Update the broadcasting Mac as well as listeners: this fix changes the sender.
No audio-quality reduction, volume change, or wire-protocol change is involved.

The new regression reproduced 14 missing packets in a 30-packet capture burst
before the fix and preserves all 30 afterwards. All 27 media-host tests passed
locally. Full regression, strict live-timing, signing and notarization checks gate
the attached downloads. This fixes the reproduced sender loss; a new two-Mac
acoustic validation has not been performed.
