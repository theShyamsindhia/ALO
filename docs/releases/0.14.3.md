## ALO 0.14.3

ALO 0.14.3 is a focused follow-up to 0.14.2 that completes the latest room-control, DJ, chat attachment, lyrics, and icon work.

- Put the current live broadcast on DJ deck A with a bounded 32-second rewind buffer, beat/manual loops, cues, EQ, and deck B/pad mixing. Broadcasters affect room audio; listeners affect only their Mac, and voice bypasses the effects.
- Keep DJ conversion, overlay delivery, and room fan-out off the real-time audio render callback. Closing DJ Studio now cancels its pending broadcast intent instead of leaving a silent headless broadcast.
- Consolidate local room, audio-source, microphone, sync, interface, diagnostics, lyrics, version, and update controls under the bottom settings button.
- Add direct room file sharing for regular files up to 8 MB, with drag and drop, bounded authenticated transfer, immutable sender-scoped cache identities, receive admission limits, integrity checks, bounded image thumbnails, and separate development storage.
- Restore cached chat attachments after room rejoin or relaunch when their files remain available.
- Show the active lyric below the player status and keep full lyrics available from that line without posting lyrics into room chat.
- Remove the opaque white canvas from the default and selectable application icons so Dock, Finder, and notification icons use the intended rounded silhouette.
- Fix the live DJ waveform view build on current Swift toolchains.

Validation includes the strict release-mode DJ, attachment, secure-mesh, and full CI suites. Signed and notarized release artifacts are produced only by the release workflow.
