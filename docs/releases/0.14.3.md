## ALO 0.14.3

DJ Studio can now use the music already playing in a room broadcast. No imported audio file is required.

- Select Live broadcast on deck A for a visible waveform, up to 32 seconds of rewind, beat/manual loops, cues, gain and three-band EQ. Broadcaster changes affect the room; listener changes affect only that Mac. Voice chat bypasses DJ effects.
- Press the red REC beside either deck to capture the original broadcast, then Stop to load a playable take. Capture stops automatically at 32 seconds. On A, Play take replaces the live input; on B, Play and the crossfader blend the recording alongside it. Captured takes support scrubbing, tempo, EQ, cues and loops.
- Add configurable record/stop keys U and I, preserving existing custom keyboard assignments. The in-app Guide explains the recording workflow.
- Keep recording storage bounded: one capture buffer, up to 32 seconds per take and approximately 6.15 MB of temporary audio per deck. Finished takes are removed when replaced, cleared, or DJ Studio closes. No sound packs or song downloads are bundled.
- Clear prior live history on broadcaster changes and prevent stale overlays when returning to live audio.
- Fix live-waveform compilation on the pinned release toolchain.
- Include the room file-sharing, lyrics, consolidated settings and version/update access added since 0.14.2.

Live processing follows incoming broadcast packets. Recorded / file mode lets captured takes play locally independently of that source; stop the original broadcast and choose Share DJ mix to share an independent recorded mix. Separate headphone routing, hardware MIDI, automatic beat detection and recording export remain unavailable.
