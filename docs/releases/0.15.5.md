# ALO 0.15.5

- Fix shared video stalling when the room negotiates a longer playback delay. Preserve frames waiting for their display time while keeping decoded-image memory bounded.
- Stop unchanged capture timestamps from redrawing annotation controls or repeatedly repositioning the presenter's overlay. Keep geometry, permission and source-availability changes responsive.
- Start screen annotations with a compact Annotate control. Open the tools when needed; closing them stops drawing without removing shared annotations.

Update both the presenter and viewers. Audio playback timing, audio buffering and
the room protocol are unchanged.

The queue regression covers continuous 720p playback at 250, 350 and 600 ms,
large-frame memory pressure, and cancellation. An independent check of the actual
queue changed from zero frames displayed during input at 350/600 ms to continuous
delivery. Annotation regressions cover timestamp-only updates and suspended input.
Full Mac regressions, strict live timing, signing, notarization and clean-machine
distribution checks gate the downloads. A physical two-Mac video session has not
been revalidated for this patch.
