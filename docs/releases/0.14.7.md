# ALO 0.14.7

ALO 0.14.7 removes the generated exterior shadow that appeared as a broken gray or white border around app icons.

- Clips the default icon and all 15 optional icons to their actual rounded front faces.
- Preserves each icon's logo, color, bevel, and antialiased edge while removing the protruding shadow skirt.
- Refreshes on-demand icon downloads from an immutable repaired source revision.
- Moves downloaded icons to a new cache generation so previously cached broken assets are not reused.
- Adds alpha-bound regression coverage for every icon variant.
